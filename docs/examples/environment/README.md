# A test environment for 128 boards

Made with `pcbtestkit environment build` for 110 boards generated by `examples/make_collection.py` (seed 7), then KiCad's demo projects added with `pcbtestkit environment add` (the station video shows the demos after the boards it showed first). Start with [index.html](index.html), [requirements.md](requirements.md), [constraints.md](constraints.md) (what limits every board) and [upgrades.md](upgrades.md) (what an upgrade would gain and cost).

Everything at the environment and station level is here: the stations' KiCad boards, pages and videos, the ranking and every board's profile. Of the boards' own outputs (guide, fixture, nest and clamp parts, jigs, runner: about 23 MB per board, 2.7 GB in all) only the first 3 of each station are kept; `python3 tools/regen_examples.py --only environment` makes all of them.
