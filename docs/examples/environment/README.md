# A test environment for 128 boards

Made with `pcbtestkit environment build` for 110 boards generated by `examples/make_collection.py` (seed 7), then KiCad's demo projects added with `pcbtestkit environment add` (the station video shows the demos after the boards it showed first). Start with [index.html](index.html), [requirements.md](requirements.md), [constraints.md](constraints.md) (what limits every board) and [upgrades.md](upgrades.md) (what an upgrade would gain and cost).

Everything at the environment and station level is here: the overview video, the stations' KiCad boards, pages and videos, the ranking and every board's profile. Every board's own outputs (guide, report, fixture, nest and clamp parts, jigs, runner) come to about 3 GB, so the repository keeps 5 boards, each with its explainer video:

* [sensor_20](stations/station-1/sensor_20/sensor_20-guide.html)
* [usb_dongle_09](stations/station-1/usb_dongle_09/usb_dongle_09-guide.html)
* [CM5 MINIMA](stations/station-1/CM5_MINIMA_3/CM5_MINIMA_3-guide.html)
* [Antmicro Baseboard for Jetson AGX Thor](stations/station-1/jetson-agx-thor-baseboard/jetson-agx-thor-baseboard-guide.html)
* [KiCad demo](stations/station-2/video/video-guide.html)

[.gitignore](.gitignore) lists them; `python3 tools/regen_examples.py --only environment` makes the catalog again and keeps the boards it lists.
